# Cadivor SOC 2 readiness plan

Status: planning document. Cadivor does not currently claim SOC 2 or ISO 27001 certification, and no audit has begun.

## Work plan

1. **Scope and ownership** — name a control owner, define the product and infrastructure boundary, inventory production systems, and identify customer data flows.
2. **Policies and evidence** — approve access control, change management, incident response, backup/restore, vendor review, vulnerability management, and data retention procedures.
3. **Technical controls** — document production access, MFA expectations, secrets handling, deployment approvals, logging, alerting, backups, and deletion workflows; close gaps before selecting an auditor.
4. **Evidence period** — operate the approved controls consistently, retain evidence, review exceptions, and complete an independent readiness assessment.
5. **Audit decision** — select a qualified auditor and determine the appropriate SOC 2 scope and Type I or Type II path after the readiness assessment.

## Initial work items

- Confirm provider configuration and contractual subprocessor details for each production environment.
- Add a verified account deletion workflow and document retention periods for account, BOM, audit, billing, and backup records.
- Confirm production backup, restore, encryption-at-rest, and incident-notification settings with each provider.
- Establish a security contact, incident escalation owner, and customer communication process.
- Maintain a dated risk register and assign owners and evidence locations for each control.

This plan is an internal readiness outline, not a certification statement or guarantee of compliance.
