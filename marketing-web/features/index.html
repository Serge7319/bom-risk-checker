GUIDED FIRST RUN

ONE-TIME REPORT

Make the decision traceable and shareable

DECISION RECORDS

Capture the why with the action

Save the chosen action, source evidence, owner, confidence context, and approval history. Changes to a BOM create a new revision so earlier report history remains available.

REVIEWER ACCESS

Share a report or invite one approver

Use read-only links for report sharing. Invite an approver to a single decision record with approver-only access, without granting workspace-wide editing access.

PORTFOLIO VIEW

See work across saved BOMs

Review portfolio health, open high-severity blockers, decisions awaiting approval, and opted-in monitored BOMs from one leadership view.

Keep an eye on selected parts

Monitoring is opt-in. Checks apply to selected parts in eligible saved analyses; source credentials and scheduler readiness determine whether a check can contact suppliers.

SCHEDULED CHECKS

Review lifecycle and supply changes

Opted-in workspaces can use the six-hour scheduled cadence. Email alert notifications and a weekly digest require user preferences, verified account email, and enabled email delivery.

SLACK DELIVERY

Send alert summaries to a channel

Workspace admins can connect an incoming Slack webhook and enable channel alerts. Delivery requires a saved connection and matching monitoring preferences; messages link back to Cadivor.

Connect the engineering workflow

Bring in a BOM from common tools, use the API for custom workflows, and keep the limits of each data source visible.

KICAD

Send the open board BOM from KiCad

The Cadivor KiCad action uses KiCad’s IPC API to read component fields from the open board, submit the BOM, and open the saved report. It does not upload the board layout or routing.

CSV AND PLM/ERP

Import and export practical BOM files

Use common CSV and Excel columns, starter templates, and neutral CSV exports for downstream PLM or ERP review. Draft medical-device and aerospace decision-record layouts are available for compliance review; they do not certify a product.

PUBLIC API AND WEBHOOKS

Build Cadivor into your tools

Workspace-scoped API keys, request limits, and signed outgoing webhooks support custom integrations. Webhooks include completed API analyses and source-backed alerts from live scheduled checks.

SUPPLIER INTELLIGENCE

Compare the sources configured for your workspace

Cadivor supports DigiKey, Mouser, and Newark lookups. Nexar Supply can be enabled when its provider credentials are configured. Coverage varies by part and source; a catalog listing does not establish seller authorization or engineering compatibility.

COMPLIANCE AND LIFECYCLE

Keep unknown data marked unknown

Component-level exports can include RoHS, REACH, PFAS, PCN, last-time-buy, and end-of-life evidence when a source record is available. Missing values are not estimated; source-linked alerts appear only when supported by verified evidence.

ADMIN AUDIT

Export workspace activity

Workspace admins can export audit activity and review who changed or approved a decision, with timestamps and linked record context.

PLAN-AWARE ACCESS

See features that match your account

Plan entitlements control access to analyses, monitoring, collaboration, and API features. Annual billing and add-ons appear when their Stripe prices and account configuration are available; the active price is shown before checkout.
