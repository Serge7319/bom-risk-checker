DEVELOPER API

Connect BOM analysis to your workflow.

The v1 API accepts a BOM upload, saves the resulting analysis to your workspace, and lets authorized integrations list and retrieve its reports.

Access and limits

API ACCESS

Workspace-scoped keys

Create an API key in Cadivor under Settings → Billing → Developer API keys. API access is included with Trial, Business, and Enterprise; Professional requires the API add-on. Copy the secret when it is created; Cadivor shows it once. Revoking API access, the key, or workspace membership disables it.

RATE LIMITS

Per-key request limits

General v1 requests are limited to 180 per minute per API key. Analysis submissions are limited to 5 per minute per key. A limit response uses HTTP 429; wait before retrying. BOM uploads are limited to 10 MB.

Send the key as Authorization: Bearer <API_KEY> or X-API-Key: <API_KEY>. Treat it as a password: store it server-side and never put it in a browser app or public repository.

Endpoints

Method and pathPurpose
POST /v1/analysesSubmit multipart/form-data with a file field containing the BOM. The response includes the saved analysis ID and report links.
GET /v1/reports?limit=25&offset=0List workspace reports. Limit is 1–100; offset is 0–100,000.
GET /v1/reports/{analysis_id}Retrieve one report that is visible to the API key’s workspace.

Submit a BOM

Replace the API base and key with your deployment values. This example reads the synchronous analysis response and prints the saved report endpoint.

curl --fail-with-body -H "Authorization: Bearer $CADIVOR_API_KEY" -F "file=@./bom.csv" "${CADIVOR_API_BASE%/}/v1/analyses"

A successful response includes analysis_id, report_url, and report_endpoint. Use GET /v1/reports/{analysis_id} to retrieve the full saved report later.

Analyze an open PCB from KiCad

You do not need to write an API client for the standard KiCad workflow. Install the Cadivor IPC action, add a workspace API key once, and run the action from PCB Editor. It submits the component BOM and opens the saved Cadivor report in your browser.

Download the KiCad plugin Create an API key
SETUP

What you need

  1. KiCad 9.0.5 or newer with its IPC API server enabled.
  2. API access for your Cadivor workspace and a supported operating-system credential manager.
  3. An MPN custom field on every populated footprint included in the BOM. Manufacturer and Description fields are optional.
DATA HANDLING

What the action sends

It reads manufacturer part number, manufacturer, description/value, quantity, references, and footprint from the open PCB. Excluded and do-not-populate footprints are skipped. If an included footprint has no MPN or reference, the action stops before uploading.

The PCB board file, schematic, placement, nets, and routing are not uploaded. Cadivor receives the component rows and applies the workspace’s existing analysis limits and supplier settings.

  1. Unzip cadivor-kicad-plugin.zip into KiCad’s versioned plugins folder, then restart KiCad.
  2. In Cadivor Settings → Billing → Developer API keys, create a key. On the plugin’s first run, paste it into the prompt; it is saved in your operating-system keychain.
  3. Open a PCB in PCB Editor and choose Analyze BOM with Cadivor. Review the upload confirmation and the resulting saved report.

The key is for authentication; the downloadable plugin performs the KiCad-to-Cadivor handoff. Revoke the key in Cadivor Settings if you no longer use that integration. Removing it from one computer’s keychain does not revoke it elsewhere.

Signed event webhooks

Workspace owners and admins with API access can add an HTTPS destination from Settings → Billing → Developer API keys → Outgoing webhooks. Cadivor encrypts the URL and signing secret at rest; the secret is shown once.

EventWhen it is sent
analysis.completedA BOM submitted through POST /v1/analyses has been saved.
monitoring.alerts.createdA live scheduled check records a new source-backed alert for an opted-in workspace.
webhook.testA workspace admin sends a test from Settings.

Every delivery includes X-Cadivor-Webhook-Id, X-Cadivor-Webhook-Event, X-Cadivor-Webhook-Timestamp, and X-Cadivor-Webhook-Signature. Verify the HMAC-SHA256 signature against the exact raw body with your one-time signing secret before parsing the JSON. Failed deliveries retry with backoff up to five times; recent attempts appear in Settings. Cadivor rejects redirects and destinations that resolve to private or reserved IP addresses.

Monitoring webhooks are emitted only after a live scheduled check finds a source-backed change. A dry run makes no supplier calls and sends no webhooks.

Webhook payloads can contain workspace information such as part numbers, alert details, and evidence links. Subscribe only endpoints authorized to receive those data.

Need an API key?

Professional workspace owners and admins can create or revoke keys in Cadivor billing settings.
