DEVELOPER API

Connect BOM analysis to your workflow.

The v1 API accepts a BOM upload, saves the resulting analysis to your workspace, and lets authorized integrations list and retrieve its reports.

Access and limits

API ACCESS

Workspace-scoped keys

Open APIs in the Cadivor workspace navigation to create or revoke a key. API access is included with Trial, Business, and Enterprise; Professional requires the API add-on. Copy the secret when it is created; Cadivor shows it once. Revoking API access, the key, or workspace membership disables it.

RATE LIMITS

Per-key request limits

General v1 requests are limited to 180 per minute per API key. Analysis submissions are limited to 5 per minute per key. A limit response uses HTTP 429; wait before retrying. BOM uploads are limited to 10 MB.

Send the key as Authorization: Bearer <API_KEY> or X-API-Key: <API_KEY>. Treat it as a password: store it server-side and never put it in a browser app or public repository.

Endpoints

Method and pathPurpose
POST /v1/analysesSubmit multipart/form-data with a file field containing the BOM. The response includes the saved analysis ID and report links.
GET /v1/reports?limit=25&offset=0List workspace reports. Limit is 1–100; offset is 0–100,000.
GET /v1/reports/{analysis_id}Retrieve one report that is visible to the API key’s workspace.

Submit a BOM

Replace the API base and key with your deployment values. This example reads the synchronous analysis response and prints the saved report endpoint.

curl --fail-with-body -H "Authorization: Bearer $CADIVOR_API_KEY" -F "file=@./bom.csv" "${CADIVOR_API_BASE%/}/v1/analyses"

A successful response includes analysis_id, report_url, and report_endpoint. Use GET /v1/reports/{analysis_id} to retrieve the full saved report later.

Analyze an open PCB from KiCad

If KiCad says Cadivor could not be reached, the health URL may still open in your browser while KiCad’s Python cannot connect. The latest plugin uses a bundled Mozilla CA list for HTTPS and reports identifiable DNS, TLS, or timeout causes. If you update the plugin requirements, recreate its environment under Preferences → PCB Editor → Plugins. HTTP 401/403 responses are shown separately as API key or access problems.

You do not need to write an API client for the standard KiCad workflow. Install the Cadivor IPC action, add a workspace API key once, and run the action from PCB Editor. It submits the component BOM and opens the saved Cadivor report in your browser.

SETUP

What you need

  1. KiCad 9.0.5 or newer, with Enable KiCad API turned on in the standalone Preferences → Plugins page.
  2. API access for your Cadivor workspace and a supported operating-system credential manager.
  3. An MPN custom field on every populated footprint included in the BOM. Manufacturer and Description fields are optional.
DATA HANDLING

What the action sends

It reads manufacturer part number, manufacturer, description/value, quantity, references, and footprint from the open PCB. Excluded and do-not-populate footprints are skipped. If an included footprint has no MPN or reference, the action stops before uploading.

The PCB board file, schematic, placement, nets, and routing are not uploaded. Cadivor receives the component rows and applies the workspace’s existing analysis limits and supplier settings.

Install and run the action

  1. Unzip the download and copy kicad-cadivor into the versioned KiCad plugins directory. Keep plugin.json directly inside that folder. Paths are ~/Documents/KiCad/<version>/plugins/kicad-cadivor/ on macOS, %USERPROFILE%\Documents\KiCad\<version>\plugins\kicad-cadivor\ on Windows, and ~/.local/share/KiCad/<version>/plugins/kicad-cadivor/ on Linux. Replace <version> with your KiCad version folder, such as 9.0 or 10.0.
  2. In KiCad’s Preferences dialog, select the standalone Plugins page near the bottom of the left sidebar and enable Enable KiCad API. In PCB Editor → Plugins, confirm Analyze BOM with Cadivor is listed and Show Button is checked.
  3. Click OK, then fully quit and reopen KiCad. On first launch, KiCad builds an isolated Python environment and installs the plugin dependencies; allow that setup to finish.
  4. In Cadivor, open APIs from the workspace navigation and create a key. Cadivor shows the secret once. On the plugin’s first run, paste it into the prompt; the plugin saves it in your computer’s credential store (Keychain on macOS, Credential Manager on Windows, or Secret Service on Linux). It stays available across KiCad restarts and Cadivor website logouts, so you do not need to create or paste a key for every analysis.
  5. Open a PCB in PCB Editor and choose Tools → External Plugins → Analyze BOM with Cadivor, or click the Cadivor BOM button in the top toolbar. Review the upload confirmation; Cadivor then saves the analysis and opens its report in your browser.

If you are on Windows and are unsure where to install the plugin, open Preferences → PCB Editor → Plugins and click the folder button below the plugin list; this opens KiCad’s user plugin folder. The default is %USERPROFILE%\Documents\KiCad\<version>\plugins. Copy the complete kicad-cadivor folder there and keep plugin.json directly inside it. If the action is missing, confirm that the standalone Preferences → Plugins page has Enable KiCad API checked and that the action appears under PCB Editor → Plugins. Use Tools → External Plugins → Refresh Plugins, then reopen that submenu. If the action is listed in Preferences but is still missing, right-click its row (on a Mac trackpad, use a two-finger click), choose Recreate Plugin Environment, wait for setup to finish, and close and reopen PCB Editor. Use the warning/errors control at the bottom of that Preferences page if setup reports a problem. If clicking the action exits with TclError: Can't find a usable init.tcl, replace the installed plugin folder with the latest download and restart KiCad; this is an older prompt's missing Tcl/Tk dependency, and you do not need to install Tcl/Tk manually. The updated macOS action uses native system dialogs. After its first-run API-key prompt, it asks you to confirm before sending; if the board has included footprints without MPN custom fields, it lists them and sends nothing. If an older report shows values such as BoardText(value=LM358DR, position=Vector2(...), layer=...), replace the plugin and rerun the analysis; those are KiCad object details, not component data. The API listening message confirms KiCad’s server is running; it does not confirm the action has loaded. Verify that plugin.json is in the versioned plugins folder above. The Reveal Preferences in Finder button opens KiCad’s settings folder, not the plugin installation folder. The key is for authentication; the downloadable plugin performs the KiCad-to-Cadivor handoff. Revoke the key in Cadivor Settings if you no longer use that integration. Removing it from one computer’s credential store does not revoke it elsewhere.

Signed event webhooks

Workspace owners and admins with API access can add an HTTPS destination from Settings → Billing → Developer integrations → Outgoing webhooks. Cadivor encrypts the URL and signing secret at rest; the secret is shown once.

EventWhen it is sent
analysis.completedA BOM submitted through POST /v1/analyses has been saved.
monitoring.alerts.createdA live scheduled check records a new source-backed alert for an opted-in workspace.
webhook.testA workspace admin sends a test from Settings.

Every delivery includes X-Cadivor-Webhook-Id, X-Cadivor-Webhook-Event, X-Cadivor-Webhook-Timestamp, and X-Cadivor-Webhook-Signature. Verify the HMAC-SHA256 signature against the exact raw body with your one-time signing secret before parsing the JSON. Failed deliveries retry with backoff up to five times; recent attempts appear in Settings. Cadivor rejects redirects and destinations that resolve to private or reserved IP addresses.

Monitoring webhooks are emitted only after a live scheduled check finds a source-backed change. A dry run makes no supplier calls and sends no webhooks.

Webhook payloads can contain workspace information such as part numbers, alert details, and evidence links. Subscribe only endpoints authorized to receive those data.

Need an API key?

Workspace owners and admins can create or revoke API keys from the APIs page. Professional workspaces need the API add-on.
